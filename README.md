# Sensol Website

Marketing site for Sensol: AI-native software built for SEND.

Static HTML/CSS/JS, with no build step. The font is EB Garamond (Apple Garamond is used where it's installed).

## Files
- index.html: landing page
- signup.html: waitlist, council pilot and partnership sign-up (?intent=waitlist|pilot|partner)
- styles.css (shared by both pages)

## Publish on GitHub Pages
Settings → Pages → Deploy from a branch → main / (root).
